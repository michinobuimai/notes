    # Aussagen - Aussageformen







        # Vereinigungen/Schnitt von mengen in familien von einer Grundmenge
            ( Mengenmengen werden oft als Familie F bezeichnet )

                ∪_( M ∈ F ) M := {x ∈ G | ∃M ∈ F : x ∈ M}
                ∩_( M ∈ F ) M := {x ∈ G | ∀M ∈ F : x ∈ M}

            für F = ∅    liefern:

                ∪_( M ∈ F ) M = ∅ bzw. M = {}  und      ∩_( M ∈ F ) M = G

            wieso?

                für {x ∈ G | ∃M ∈ ∅ : x ∈ M}

                Es gibt keine Menge in das ein element der leeren Menge ist.
                Dadurch fällt die Bedingung weg das x ∈ M ist
                Und Weil M nie definiert wird liefert es den wahrheitswert falsch zurrück.
                
                somit initiert die vereinigung eine menge, die jedoch nicht befüllt wird.
