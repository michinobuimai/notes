        Für eine Abbildung f : X → Y ist
            (i) das Bild von A ⊆ X unter f die Menge        f   (A) := {y ∈ Y | ∃x ∈ A : f (x) = y},
            (ii) das Urbild von B ⊆ Y unter f die Menge     f^-1(B) := {x ∈ X | f (x) ∈ B}.

        Per Definition der Abbildung f : X → Y , gilt f^−1(Y ) = X.
        Andersherum gilt nur         f (X) ⊆ Y , aber nicht immer Gleichheit.

        Für eine Abbildung                  g : X → Y, x ↦ → g(x) und A ⊆ X
        definieren wir die Schreibweise:    {g(a) | a ∈ A} := g(A).

        Eine Abbildung f : X → Y heißt
            (i) surjektiv,                
                    falls f (X) = Y ,bzw.  ∀y ∈ Y   ∃x ∈ X : f(x) = y                              
            (alle Elemente aus Y können aus X abgebildet werden [eine Zuordnung besitzen])
                
            (ii) injektiv,
                    falls ∀x1, x2 ∈ X : (x1 =/= x2) ⇒ (f (x1) =/= f (x2)),
            (jedes Element aus Y muss aus höchstens ein Element aus X abgebildet werden.)

            (iii) bijektiv,
                    falls sie surjektiv und injektiv ist. Dann ist f eine Bijektion von X nach Y

            # Bijektivität (Surjektivität + Injektivität)
                Eine Abbildung f : X → Y ist genau dann bijektiv, wenn für jedes y ∈ Y genau ein x ∈ X mit f (x) = y existiert.
                

                Beweis:
                    Sei f zunächst bijektiv.
                    Wegen der Surjektivität von f existiert per Definition zu jedem y ∈ Y mindestens ein x ∈ X mit f (x) = y.
                    Sind x1, x2 ∈ X mit f (x1) = f (x2) = y, so folgt aus der Injektivität x1 = x2.
                    Somit gibt es genau ein solches x.
                    
                    Nehmen wir umgekehrt an, dass für jedes y ∈ Y ein eindeutiges x ∈ X mit f (x) = y existiert.
                    Dann ist f (X) = Y , also f surjektiv.
                    Sind x1, x2 ∈ X mit f (x1) = f (x2) = y, so sind x1 und x2 Urbilder desselben Elements y ∈ Y .
                    Aus der Eindeutigkeit folgt x1 = x2, also ist f auch injektiv und damit bijektiv.

        # Verkettung, einsetzen einer Funktion f in g
            Die Verkettung zweier Abbildungen f : X → Y und g : Y → Z
            ist die Abbildung g ◦ f : X → Z, x ↦ (g ◦ f)(x) := g(f(x)).

        Die eindeutig bestimmte Abbildung f^−1 aus Satz 1.76 heißt Umkehrabbildung (bzw. Umkehrfunktion) von f.
         Ist f eine bijektive Abbildung, dann auch f^-1 und es gilt (f^−1)^−1 = f.

    succ: ℕ → ℕ, n ↦ (n ∪ {n})

    Satz 2.5. Jedes n ∈ N \ {0} ist Nachfolger einer anderen Zahl, es existiert also m ∈ N mit succ(m) = n. 

    Das Tupel (N,n_0,succ) erfüllt die Peano-Axiome, wenn:

        P1. n_0 ∈ N (existenz der null)

        P2. succ: N → N ist eine Abbildung (Jede Zahl hat einen Nachfolger)

        P3. ∀n ∈ N: succ(n) ≠ n_0

        P4. succ ist injektiv.

        P5. ∀M ⊆ N: (n_0 ∈ M ∧ succ(M) ⊆ M ) ⇒ M = N. 

    Die Menge der natürlichen Zahlen (von Neumann) ist ℕ := {∅,{∅},{∅,{∅}},{∅,{∅},{∅,{∅}}},...}
    Dabei ist jedes Element die Menge der vorherigen Elemente.

    0 :=                 ∅,
    1 := {0} =          {∅},
    2 := {0,1} =        {∅, {∅}}
    3 := {0,1,2} =      {∅, {∅}, {∅,{∅}}}
    4 := {0,1,2,3} =    {∅, {∅}, {∅{∅}}, {∅,{∅},{∅,{∅}}}}
    5 := {0,1,2,3,4} =  {∅, {∅}, {∅{∅}}, {∅,{∅},{∅,{∅}}}, {∅,{∅},{∅{∅}},{∅,{∅},{∅,{∅}}}} }
