        # Vereinigungen/Schnitt von mengen in familien von einer Grundmenge
            ( Mengenmengen werden oft als Familie F bezeichnet )

                ∪_( M ∈ F ) M := {x ∈ G | ∃M ∈ F : x ∈ M}
                ∩_( M ∈ F ) M := {x ∈ G | ∀M ∈ F : x ∈ M}

            für F = ∅    liefern:

                ∪_( M ∈ F ) M = ∅ bzw. M = {}  und      ∩_( M ∈ F ) M = G

            wieso?

                für {x ∈ G | ∃M ∈ ∅ : x ∈ M}

                    Es gibt keine Menge in das ein element der leeren Menge ist.
                    Dadurch fällt die Bedingung weg das x ∈ M ist
                    Und Weil M nie definiert wird liefert es den wahrheitswert falsch zurrück.
                    somit initiert die vereinigung eine menge, die jedoch nicht befüllt wird.

                für {x ∈ G | ∀M ∈ ∅ : x ∈ M}

                    kann man umformen zu: {x ∈ G | ¬(∃M ∈ ∅ : x ∉ M)}
                    die Bedingung ¬(∃M ∈ ∅ : x ∉ M) liefert wahr weil

                    (∃M ∈ ∅ : x ∉ M) liefert einen falschen wert weil es keine menge M in der Leeren menge
                    geben kann und weil die negation einer Falschen Aussage eine Wahre Aussage ist,
                    wird die Bedingung für x ∈ G immer erfüllt somit ist jedes Element in G
                    in der Schnittmenge ∩_( M ∈ F ) M für F = ∅ vorhanden.

    # Relationen R ⊆ N x M
        Definition: Eine Relationzwischen Mengen M und N ist eine Menge R ⊆ N x M.
                    Wir schreiben xRy für x,y ∈ R "x steht in Relation zu y"

        ≤ := { (n,m) ∈ ℕ x ℕ | ∃k ∈ ℕ : m = n + k }

        < := {(n, m) ∈ ℕ × ℕ | n ≤ m ∧ n = m}




        reflexiv            ∀x ∈ X       :   xRx

        symmetrisch         ∀x , y ∈ X   :   ( xRy ⇒ yRx )

        antisymmetrisch     ∀x, y ∈ X    :   ( ( xRy ∧ yRx ) ⇒ (x = y) )
            formal: Seien n ≤ m und m ≤ n.
                    Es gibt k, l ∈ N : m = n + k, n = m + l.
                    Also n = n + k + l. Wegen k, l ≥ 0 gilt k = l = 0, also n = m

        transitiv           ∀x, y, z ∈ X :   ( ( xRy ∧ yRz ) ⇒ xRz )

        Relation auf eine Menge heißt Ordnungsrelation, wenn R reflexiv antisymmetrisch und transitiv ist.
        ≼ := R und nennt (M,≼) eine partiell geordnete Menge.

        Gilt ∀x , y ∈ M : x ≼ y ∨ y ≼ x, so ist die ≼ eine Totalordnung und (M,≼) eine Total geordnete Menge.
        ((kleiner/größer) gleich, teilrelation | , oder Teilmengenrelation)

        x ∈ M ist:
            Maximum von (M,≼), falls y ≼ x für alle y ≼ M, gilt.
            Minimum von (M,≼), falls x ≼ y für alle y ≼ M, gilt.

            Die Relation ≤ auf ℕ, ℤ , ℚ, ℝ ist jeweils eine Totalordnung.

            Für jede Menge M ist ⊆ eine Ordnungsrelation auf P( M ).

            P(M) = {∅,{0},{1},{2},{0,1},{0,2},{1,2},{0,1,2}}

            M = {0,1,2}

            R := ⊆ 

            ∀M ∈ P(M) : M ⊆ M ⇒ (P(m),≼)

            Sie ist im Allgemeinen keine Totalordnung (zum Beispiel gilt weder {1} ⊆ {2} noch {2} ⊆ {1})


        Jede partiell (jede totalgeordnete Menge ist auch partiell geordnet) geordnete Menge (M, ≼) hat höchstens ein Maximum und höchstens ein Minimum.
        seien x und y jeweils Maxima oder jeweils Minima von (M, ≼). Dann gilt sowohl x ≼ y als auch y ≼ x.
        Aus der Antisymmetrie der Ordnungsrelation ≼ folgt damit x = y.
        Also kann es keine zwei verschiedenen Maxima oder Minima geben.

        Sofern sie existieren, bezeichnen wir das eindeutige Minimum einer partiell geordneten
        Menge (M, ≼) mit min M und ihr eindeutiges Maximum mit max M .

        Sei I := {x ∈ R | 0 < x ≤ 1}.
        Dann hat die total geordnete Menge (I, ≤) kein Minimum und das Maximum max I = 1.

        wieso?
            0 ist nicht teil der Menge I: 0 ∉ I
            somit ist der kleinste wert in der Menge I nie fest definiert, nicht wie 1.
            Da 1 ∈ I ist und auch der größte wert den x annehmen kann.


        Beispiele:

        M_1 := { x ∈ ℕ | 1 < x < 5} ( Minimum 2, Maximum 4 ; Infimum 2, Supremum 4)

        M_2 := { x, y ∈ ℕ>0 | 0 < x/y < 5.1} ( Infimum 0, Supremum 5.1)
